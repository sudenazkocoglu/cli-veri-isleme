# CLI Veri İşleme Egzersizi (Ödev 1.2)

Bu depo, Yazılım Mühendisliği staj süreçlerim kapsamında terminal araçlarını kullanarak veri işleme yetkinliklerimi geliştirmek amacıyla oluşturulmuştur.

## Proje Amacı
Python veya harici kütüphaneler kullanmadan, sadece Linux terminal komutlarını (`wc`, `cut`, `sort`, `uniq`, `awk`, `join` vb.) kullanarak büyük veri setleri üzerinde analiz yapmak ve bu süreçleri raporlamak.

## İçerik
- **notes/cli-exercises.md:** Yapılan analiz adımları, kullanılan terminal komutları ve elde edilen sonuçların detaylı raporu.

## Öğrenilen Terminal Araçları
- `wc`: Satır ve kelime sayımı.
- `cut`: Sütun seçme.
- `sort` & `uniq`: Frekans analizi ve sıralama.
- `awk`: Koşullu veri filtreleme.
- `join`: Veri birleştirme işlemleri.
